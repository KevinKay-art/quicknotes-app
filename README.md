\# QuickNotes



QuickNotes is a simple note-taking web app that lets users create, organize, search, and delete notes by category. Notes can be assigned to Personal, Work, or Study categories, and they are saved in the browser so they remain available after refreshing the page.



\## Features



\- Add notes with Personal, Work, or Study categories

\- Validate notes to prevent empty notes and notes longer than 200 characters

\- Display the date and time each note was created

\- Delete individual notes

\- Search notes using case-insensitive text search

\- Save notes to localStorage

\- Load saved notes when the page opens

\- Display the correct note count

\- Responsive layout for smaller screens



\## How to Run Locally



1\. Download or clone this repository.

2\. Open the project folder in a terminal.

3\. Start a local server with:

&#x20;  `python -m http.server 8000`

4\. Open `http://localhost:8000` in your browser.

5\. Use QuickNotes to add, search, and delete notes.
